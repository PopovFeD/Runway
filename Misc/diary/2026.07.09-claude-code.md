# Что сделано

## 1. ITransport + выбор порта в GUI (коммит "Выбор порта в GUI…")

* Введён общий `ITransport` (DisplayName, `GetAvailableEndpoints()`,
  `Open(endpoint)`, события). Ключевая идея — endpoint как строка-адрес
  («COM6» / будущий «ip:port»), а конфигурация типа канала (baud rate) —
  в конструкторе реализации из настроек.
* Перечисление точек подключения переехало ВНУТРЬ транспорта — у каждого
  типа канала свой способ обнаружения. Поэтому `ISerialTransport`,
  `IPortLister`, `SerialPortLister` удалены: абстракция добавила один
  интерфейс, но убрала два.
* `WifiTransport` — заглушка под ESP32: пустой список точек (кнопка
  «Подключить» без выбранной точки выключена), прямой `Open()` бросает
  `NotSupportedException` — программная ошибка падает громко.
* Автоподключения при старте больше нет: `PortName` из настроек только
  предвыбирает порт в списке. Подключение/отключение — кнопками,
  доступность через `CanExecute` («Отключить» работает и при
  `Reconnecting` — как отмена ретраев).
* Тонкость: `Close()` транспорта не поднимает событий (остановка — не
  разрыв), поэтому `Disconnect` сам выставляет статус, а запоздавшие
  события закрытого транспорта игнорируются.

## 2. Ревизия логирования

Вердикт — НЕ переусложнено, изменений нет. Два файла = два разных
потребителя; `AppendOnlyFile` — общий код, а не лишний слой; свой
`FileLoggerProvider` дешевле Serilog. Подробно — Misc/docs/logging.md.

## 3. UX-доводка + SQLite (коммит "Индикатор активного соединения…")

* `StatusText` — индикатор ФАКТА («Подключено: Serial (COM) · COM6»),
  а не выбора в ComboBox: листание списков не путает индикатор. Выбран
  вместо автоотключения при смене транспорта — листание не должно рвать
  живое соединение.
* Кнопка «Обновить» → «Обновить список» (читалась как «обновить
  подключение»).
* `Core/Storage`: `ITelemetryStore`/`TelemetryRecord` +
  `SqliteTelemetryStore` (Microsoft.Data.Sqlite, без EF). Запись — из
  `ProcessFramesAsync`, ровно куда и планировали при вводе
  `Channel<Frame>`. Ошибка БД → `StoreError` в лог, конвейер живёт.
  `ReadAll()` пока вне интерфейса (нужен тестам; войдёт с просмотром
  истории). Misc/docs/storage.md.
