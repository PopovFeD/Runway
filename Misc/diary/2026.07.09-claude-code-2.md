## Контекст

Появился GUI-макет (`Misc/gui_mockups/`): вкладки Дашборд (плитки
T/H/давление/свет + живой вывод), Подключение, Команды, Экспорт, Настройки;
статус-бар. Решено: плитки Дашборда появляются по мере поступления типов
сообщений — модульно.

## Что сделано

1. **Типизация протокола** (закрыт давний TODO): `PacketParser.Parse`
   возвращает `abstract record Packet`; служебные сообщения — `ControlPacket`
   (строки-метки "PING" ушли). Формат строк в логе не изменился.
2. **Новый тип сообщения `Environment = 0x11`** (давление uint32 Па +
   освещённость uint32 сотых люкса, LE) — сквозь весь стек: MessageType,
   parser/builder, строка в ProcessFramesAsync, эмулятор (каждый 5-й кадр),
   тесты (roundtrip build→parse). Это данные под плитки Дашборда и
   демонстрация цены расширения протокола: ~1 record + 2 метода + константа
   в Python.
   **В БД Environment пока НЕ пишется** — схема таблиц ждёт решения ниже.
3. **Принято решение по «БД vs логи»** — `Misc/docs/storage-and-logs-decision.md`.
   Кратко: догадка автора верна; SQLite = sessions/telemetry/events с
   фильтрами во вкладке логов; diagnostics-файл остаётся один, как резерв
   на случай недоступной БД; runway.log упраздняется. До вёрстки MVVM
   достаточно шага 1 (sessions + session_id).

## Дополнение (поздний вечер): загадка флаки-тестов решена

`dotnet test` без фильтра запускает и интеграционные тесты. Падали именно
они — `UnauthorizedAccessException: Access to the path 'COM4' is denied` на
`_emulatorPort.Open()`: пара com0com существует, но ЗАНЯТА (обычно запущенным
Python-эмулятором или самим приложением). Порты свободны → 0 ошибок, один
занят → 1–2. Никаких гонок в коде не было.

Исправление: `TestEnvironmentIsReady` — перед тестом порты пробуются
открыться; занято/нет пары → мягкий скип с пометкой `[SKIP]` в консоли
вместо провала (динамического Skip в xunit 2.x нет без сторонних пакетов).

Предупреждения NU1903: транзитивный `SQLitePCLRaw.lib.e_sqlite3 2.1.11`
с уязвимым нативным SQLite (GHSA-2m69-gcr7-jv3q). В Runway.csproj добавлена
прямая ссылка на `SQLitePCLRaw.bundle_e_sqlite3 2.1.12` — версия без NuGet,
если предупреждение останется/restore не найдёт — поднять через
`dotnet add Runway package SQLitePCLRaw.bundle_e_sqlite3`.
